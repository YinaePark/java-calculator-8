# java-calculator-precourse
## 기능 요구사항

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

### 구분자 규칙
- 쉼표(`,`) 또는 콜론(`:`)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환
- 커스텀 구분자 지정 가능: 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자를 커스텀 구분자로 사용
- 잘못된 값 입력 시 `IllegalArgumentException` 발생 후 애플리케이션 종료

### 입출력
- **입력**: 구분자와 양수로 구성된 문자열
- **출력**: 덧셈 결과

## 구현할 기능 목록

### 입출력 처리
- [x] 문자열 입력받기
- [x] 계산 결과 출력하기

### 문자열 파싱
- [x] 빈 문자열 처리 → 입력이 null 또는 비어 있으면 빈 배열 반환
- [x] 기본 구분자(쉼표, 콜론) 기준으로 문자열 분리
- [x] 커스텀 구분자 파싱
  - [x] `//`와 개행(`\n`) 사이에서 커스텀 구분자 추출
  - [x] 커스텀 구분자 유효성 검증 (빈 값, 잘못된 형식 검사)
  - [x] 커스텀 구분자가 있을 경우 해당 구분자로 숫자 부분 분리
- [x] 입력 내 `\n` 리터럴을 실제 개행 문자로 정규화

### 숫자 변환 및 계산
- [x] 분리된 문자열 토큰을 long 타입 숫자로 변환
- [x] 변환된 숫자 유효성 검증
  - [x] 빈 값 검증
  - [x] 숫자 여부 검증
  - [x] 음수 입력 검증
- [x] 합산 과정에서 오버플로 검증
- [x] 변환된 숫자들의 합 계산
- [x] 단일 숫자 입력 시 해당 숫자 반환


### 예외 처리
- [x] 빈 값 입력 검증: `requireNotEmptyToken` : 입력 토큰이 비어 있으면 예외 발생
- [x] 숫자가 아닌 문자 입력 검증: `parseLongOrThrow` : 숫자로 파싱 불가능한 경우 예외 발생
- [x] 음수 입력 검증: `requireNonNegative` : 음수 값 입력 시 예외 발생
- [x] 잘못된 커스텀 구분자 형식 검증: `requireValidCustomHeader` : `//...\n` 포맷이 아닌 경우 예외 발생
- [x] 빈 커스텀 구분자 검증: `requireNonEmptyDelimiter` : 구분자가 비어 있으면 예외 발생
- [x] 계산 결과 오버플로 검증: `requireNoOverflow` : `Long` 범위를 초과할 경우 예외 발생
- [x] `IllegalArgumentException` 발생 및 메시지 처리 : 모든 검증 실패 시 일관된 예외 처리 수행  

## 추가 구현 사항 (자체 판단)
기능 요구사항에 명시되지 않은 다음 사항들을 자체적으로 판단하여 구현했습니다:
### 1. 큰 숫자 처리

문제: 큰 숫자들의 합이 int 범위(2,147,483,647)를 초과할 수 있음
해결:

자료형을 long으로 변경하여 더 큰 범위 지원
합계가 Long.MAX_VALUE를 초과하는 경우 IllegalArgumentException 발생


### 2. 공백 처리

문제: 공백이 포함된 입력에 대한 처리 방식이 명시되지 않음
해결:

공백은 커스텀 구분자로 등록한 경우에만 구분자로 사용 가능
일반 입력에서 공백이 포함된 경우 IllegalArgumentException 발생


예시:
```
입력: "// \n1 2 3"     → 정상 처리 (결과: 6)
입력: "1 , 2 , 3"      → 예외 발생 (공백은 커스텀 구분자로만 사용 가능)
```
### 3. 멀티 문자 구분자

문제: 커스텀 구분자가 여러 문자인 경우 처리 방식이 명시되지 않음
해결:

멀티 문자를 하나의 구분자로 인식하여 처리


예시:
```
입력: "//:::\n1:::2:::3"    → 정상 처리 (결과: 6)
입력: "//***\n5***10***15"   → 정상 처리 (결과: 30)
```
